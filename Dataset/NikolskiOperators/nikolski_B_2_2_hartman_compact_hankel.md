## Statement

**2.2.5. Theorem (P. Hartman, 1958).** Let $f \in L^\infty$. Then $H_f \in S_\infty$ if and only if $f \in H^\infty + C$. In other words, a Hankel operator $H$ is compact if and only if $H = H_g$ with some $g \in C(\mathbb{T})$.
