# Criteria: nikolski_A_2_4_inner_outer_factorization

**Statement:** [nikolski_A_2_4_inner_outer_factorization.md](nikolski_A_2_4_inner_outer_factorization.md) · **Lean:** [nikolski_A_2_4_inner_outer_factorization.lean](nikolski_A_2_4_inner_outer_factorization.lean)

A faithful formalization must produce, for every nonzero $f \in H^2$, a factorization $f = f_{\mathrm{inn}} f_{\mathrm{out}}$ with both factors in $H^2$, state that it is unique up to a unimodular constant (with the *compensating* inverse constant on the other factor), and state the third assertion $E_f = f_{\mathrm{inn}} H^2$. The whole fidelity question is what "outer" means: the book defines it by the shift-invariant-subspace property $E_f = H^2$, while the ground truth substitutes the exponential Poisson-integral representation — an equivalent characterization for $H^p$, but one whose defining integral is a Bochner integral of $\log\lvert f\rvert$ against a Poisson-type kernel and therefore a potential junk site.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Conclusion completeness | The theorem has **three** assertions: existence of the factorization, uniqueness up to a constant factor, and $E_f = f_{\mathrm{inn}} H^2$ (the invariant subspace generated by $f$ is the one generated by its inner factor). The third is the bridge to Beurling's theorem and is a separate mathematical claim. | ❗ The ground truth states only the first two: there is no `InnerGeneratedSubspace`-style clause identifying $E_f$ with $\theta H^2$. This is a genuine conclusion-completeness gap, and `InnerGeneratedSubspace` is already available in `Defs.lean` to express it. |
| 2 | Faithful encoding (`OuterFunction`) | The book's definition is $E_f = H^2$ (the polynomial multiples of $f$ are dense in $H^2$). The ground truth instead requires the canonical representation $g(z) = c \exp\!\big(\tfrac{1}{2\pi}\int_0^{2\pi} \tfrac{\zeta_t + z}{\zeta_t - z} \log\lvert g(\zeta_t)\rvert \, dt\big)$ with $\lvert c\rvert = 1$. | ⚠️ Equivalent for $g \in H^p$, and it is the workable choice (the subspace definition would need the closure of `θ • H²` again), but it is *not* the book's definition, so a candidate using the subspace definition should be scored at least as good. The normalization $1/2\pi$ against `volume` on `Ioc 0 (2π)` is the correct Herglotz normalization. |
| 3 | Junk values | The exponent is a Bochner integral: if $\log\lvert g\rvert$ is not integrable, mathlib returns `0` and the definition degenerates to "$g \equiv c$". One must check this does not create spurious outer functions. | ✅ Benign: the degenerate reading forces $g \equiv c$ with $\lvert c\rvert = 1$, whence $\log\lvert g\rvert = 0$ a.e. is integrable and the formula holds honestly — the junk branch is self-defeating rather than satisfiable. For fixed $z$ in the open ball the Poisson factor is bounded, so integrability of the product is exactly integrability of $\log\lvert g\rvert$. |
| 4 | Uniqueness encoding | "Unique up to a constant factor" means: if $f = \theta' g'$ is another inner–outer factorization then $\theta' = c\theta$ **and** $g' = \bar c\, g$ for one and the same unimodular $c$. Splitting this into two independent existentials, or asserting only $\theta' = c\theta$, is weaker. | ✅ `∃ c, ‖c‖ = 1 ∧ ∀ z ∈ ball 0 1, θ' z = c * θ z ∧ g' z = star c * g z` — one `c`, quantified *before* `∀ z`, with `star c = c⁻¹` on the unit circle. ❗ Trap: quantifier inversion (`∀ z, ∃ c, …`), which would allow a different constant at each point. |
| 5 | Hypothesis completeness | "$f \in H^2$, $f \ne 0$" — the nonvanishing hypothesis is essential (for $f = 0$ every $\theta$ works and uniqueness fails). Since `f : ℂ → ℂ` is total and only its restriction to the disc is constrained, "$f \ne 0$" must be read on the disc. | ✅ `hf : HardyClass 2 f` and `hnonzero : ∃ z ∈ Metric.ball (0 : ℂ) 1, f z ≠ 0`. ❗ Trap: `f ≠ 0` as functions `ℂ → ℂ`, which is satisfiable by a function vanishing identically on the disc and nonzero outside it. |
| 6 | Faithful encoding ($H^2$) | `HardyClass 2 f` is `DifferentiableOn ℂ f (ball 0 1)` together with $\sup_{0 \le r < 1} \lVert f_r \rVert_{L^2(dt)} < \infty$ — the classical radial-means definition of $H^2$, and the right one for $p = 2$. The equivalent Taylor-coefficient definition (`HardySquareSummable`) also exists in `Defs.lean`. | ✅ Correct. Note the sup is encoded as `∃ C : ℝ≥0∞, C < ∞ ∧ ∀ r ∈ [0,1), eLpNorm … ≤ C`; the `C < ∞` conjunct is what makes it a genuine boundedness statement rather than the trivial `≤ ⊤`. ⚠️ `⨆ r, eLpNorm … < ∞` would be semantically closer to "$\sup_r$". |
| 7 | Conclusion completeness (both factors in $H^2$) | The text asserts $f_{\mathrm{inn}} \in H^2$ and $f_{\mathrm{out}} \in H^2$; the exponent must travel with the outer factor (for $f \in H^p$ the outer part is in $H^p$). | ✅ `InnerFunction θ` (which bundles $H^\infty \subset H^2$) and `OuterFunction 2 g` — the parameter `2` matches the exponent of `hf`. ❗ Trap: `OuterFunction ⊤ g`, which is false in general (the outer part of an $H^2$ function need not be bounded). |
| 8 | Semantic closeness | The factorization is an identity of functions on the disc, so it must be stated pointwise on `ball 0 1` (values of the total functions outside the disc are meaningless), and likewise for the uniqueness clause. | ✅ Both `∀ z ∈ Metric.ball (0 : ℂ) 1` guarded. ⚠️ As a consequence, none of these existentials pins the functions down globally; that is unavoidable with total-function encodings but means "uniqueness" here is uniqueness on the disc only. |
