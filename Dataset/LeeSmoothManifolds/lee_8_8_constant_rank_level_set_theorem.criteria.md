# Criteria: lee_8_8_constant_rank_level_set_theorem

**Statement:** [lee_8_8_constant_rank_level_set_theorem.md](lee_8_8_constant_rank_level_set_theorem.md) · **Lean:** [lee_8_8_constant_rank_level_set_theorem.lean](lee_8_8_constant_rank_level_set_theorem.lean)

A faithful formalization must say that for **every** $c \in N$ — including the values not attained — the level set $\Phi^{-1}(c)$ is (i) closed in $M$ and (ii) an *embedded* submanifold of codimension exactly $k$, under the single global hypothesis that $\Phi$ is smooth of constant rank $k$. The mathematical difficulty is that Mathlib has essentially no embedded-submanifold API, so "embedded submanifold of codimension $k$" has to be hand-rolled; the standard faithful encoding is Lee's own local $k$-slice condition (Theorem 5.8), and the trap is to encode instead an *immersed* submanifold or a merely topological embedding. The junk-value risk is `mfderiv` inside the constant-rank predicate.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Faithful encoding | "Embedded submanifold of codimension $k$" is rendered by `EmbeddedSubmanifoldOfCodimension (m := m) {p \| Φ p = c} k`: for each $p$ in the level set there is a chart `φ ∈ IsManifold.maximalAtlas 𝓘(ℝ, Fin m → ℝ) ∞ M` with `p ∈ φ.source` and `φ '' (S ∩ φ.source) = {x ∈ φ.target \| ∀ i, m - codim ≤ i.1 → x i = 0}` — Lee's local $k$-slice condition, which characterizes embedded submanifolds. | ✅ Faithful, and it is the right call given Mathlib's thin support. ❗ Predicted error: encoding "embedded submanifold" as the existence of *some* `ChartedSpace`/smooth structure on the subtype making the inclusion an immersion (that is an **immersed** submanifold, a strictly weaker and here false-in-spirit statement), or as `IsEmbedding (Subtype.val : S → M)` alone (purely topological, says nothing smooth). |
| 2 | Junk values | `ConstantRank Φ k` measures `finrank ℝ (LinearMap.range (mfderiv … Φ p).toLinearMap)`, and `mfderiv` is `0` wherever `Φ` fails to be `MDifferentiableAt`. Without a smoothness hypothesis the predicate collapses to "`k = 0`". | ✅ `hΦ : ContMDiff 𝓘(ℝ, Fin m → ℝ) 𝓘(ℝ, Fin n → ℝ) ∞ Φ` is present. ❗ Predicted error: stating constant rank without `hΦ`, or with `hΦ` weakened to `MDifferentiable`, which is not enough for Lee's proof (the rank theorem needs $C^\infty$). |
| 3 | Quantifier structure | The rank must be constant on **all of $M$**, uniformly, and *then* every level set is claimed: `hrank` before, `∀ c, …` inside the conclusion. Lee's theorem is false if constant rank is assumed only on the level set itself; the correct weakening (his subsequent refinement) assumes constant rank on a *neighborhood* of the level set. | ✅ `hrank : ConstantRank Φ k` is a global hypothesis and `∀ c` is inside the conclusion. ❗ Predicted error: moving `c` outside and hypothesizing constant rank only on `{p \| Φ p = c}`. |
| 4 | Conclusion completeness | Both conjuncts are needed: `IsClosed {p \| Φ p = c}` **and** the submanifold clause, about one and the same set. | ✅ Both present. Note that `IsClosed` is genuinely provable here without any separation typeclass on `N`: a `ChartedSpace (Fin n → ℝ) N` is automatically T1, so `{c}` is closed and `Φ` is continuous. A candidate adding `[T2Space N]` for this purpose is harmless but unnecessary. |
| 5 | Faithful encoding | The slice is `{x ∈ φ.target \| ∀ i, m - codim ≤ i.1 → x i = 0}` — the intersection of the coordinate slice with `φ.target`, so the condition is "$\varphi(S \cap U)$ is a slice **of $\varphi(U)$**". Dropping the `x ∈ φ.target` restriction would demand that the image fill an entire coordinate hyperplane of $\mathbb{R}^m$, which is false. | ✅ Correctly relativized to `φ.target`. Using the *first* `codim` coordinates instead of the last would be an equally faithful convention (compose `φ` with a permutation, which stays in the maximal atlas). |
| 6 | Hypothesis completeness | No bound `k ≤ min(m,n)` is imposed, and none is needed: `ConstantRank` forces `k ≤ min(m,n)` whenever `M` is nonempty, and `EmbeddedSubmanifoldOfCodimension` uses truncated `m - codim`. | ✅ Cleaner than `lee_7_8`/`lee_7_13`, which carry a redundant `hk`. ⚠️ `m - codim` is ℕ-subtraction; nothing here can reach the truncated branch, but candidates using `m - k` in a setting where `k > m` is reachable should be checked. |
| 7 | Mathlib conventions / typeclass stack | Lee's smooth manifolds are Hausdorff and second countable; `[TopologicalSpace M] [ChartedSpace (Fin m → ℝ) M] [IsManifold 𝓘(ℝ, Fin m → ℝ) ∞ M]` gives neither. | ⚠️ Not needed for the truth of this (local plus T1) statement, so the Lean version is strictly more general; but it does not transcribe Lee's hypotheses, and the omission is not always benign elsewhere in this book. |
