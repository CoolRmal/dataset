## Statement

**Theorem 8.8 (Constant-Rank Level Set Theorem).** Let $M$ and $N$ be smooth manifolds, and let $\Phi \colon M \to N$ be a smooth map with constant rank equal to $k$. Each level set of $\Phi$ is a closed embedded submanifold of codimension $k$ in $M$.
