# Criteria: kallenberg_9_30_optional_sampling_and_closure

**Statement:** [kallenberg_9_30_optional_sampling_and_closure.md](kallenberg_9_30_optional_sampling_and_closure.md) · **Lean:** [kallenberg_9_30_optional_sampling_and_closure.lean](kallenberg_9_30_optional_sampling_and_closure.lean) · **Context:** [kallenberg_9_30_optional_sampling_and_closure.context.md](kallenberg_9_30_optional_sampling_and_closure.context.md)

## What the theorem says

Let $X$ be a submartingale on $\mathbb{R}_+$ with right-continuous paths, for a right-continuous
filtration, and let $\sigma$ and $\tau$ be optional times with $\tau$ bounded. Then $X_\tau$ is
integrable and $X_{\sigma \wedge \tau} \le \mathbb{E}(X_\tau \mid \mathcal{F}_\sigma)$ almost surely,
where $\mathcal{F}_\sigma$ is the $\sigma$-algebra of events known by time $\sigma$. The same
conclusion holds for unbounded optional times exactly when the positive part $X^+$ is uniformly
integrable. For an unbounded time, $X_\tau$ has to be read as the almost-sure limit
$X_\infty = \lim_{t \to \infty} X_t$ on the event $\{\tau = \infty\}$.

## What a correct formalization must contain

Each row is one thing the Lean statement has to say. A formalization that is missing any
row is incomplete.

| # | Requirement | Does the ground truth have it? |
|---|-------------|-------------------------------|
| 1 | The time index is continuous, $\mathbb{R}_+$, and the measure is a probability measure. | ✅ `ℱ : Filtration ℝ≥0 ‹MeasurableSpace Ω›`, `X : ℝ≥0 → Ω → ℝ`, `[IsProbabilityMeasure μ]`. |
| 2 | $X$ is a submartingale for $\mathcal{F}$. | ✅ `hX : Submartingale X ℱ μ`, which bundles adaptedness, integrability at each time, and the conditional inequality. |
| 3 | Both right-continuity assumptions from the text: of the filtration and of the paths of $X$. | ✅ `[ℱ.IsRightContinuous]` and `hXright : ∀ᵐ ω ∂μ, ∀ t, ContinuousWithinAt (fun s ↦ X s ω) (Ici t) t`. |
| 4 | $\sigma$ and $\tau$ are optional times allowed to take the value $+\infty$. | ✅ `σ τ : Ω → WithTop ℝ≥0` with `hσ : IsStoppingTime ℱ σ` and `hτ : IsStoppingTime ℱ τ`. |
| 5 | $\tau$ is bounded. | ✅ `hτbounded : ∃ u : ℝ≥0, ∀ᵐ ω ∂μ, τ ω ≤ u`. |
| 6 | First conclusion: $X_\tau$ is integrable. | ✅ `Integrable (stoppedValue X τ) μ`. |
| 7 | Second conclusion: the sampling *inequality*, conditioning on the $\sigma$-algebra generated by $\sigma$. | ✅ `stoppedValue X (fun ω ↦ min (σ ω) (τ ω)) ≤ᵐ[μ] μ[stoppedValue X τ \| hσ.measurableSpace]`. |
| 8 | Third conclusion: an "if and only if" between uniform integrability of $X^+$ and the extension to unbounded times. | ✅ `UniformIntegrable (fun t ω ↦ max (X t ω) 0) 1 μ ↔ …`. |
| 9 | The extension side must supply the terminal variable $X_\infty$: an almost-sure limit of $X_t$ that is itself integrable. | ✅ `∃ terminalValue : Ω → ℝ, Integrable terminalValue μ ∧ (∀ᵐ ω ∂μ, Tendsto (fun t ↦ X t ω) atTop (𝓝 (terminalValue ω))) ∧ …`. |
| 10 | The extension side quantifies over *arbitrary* optional times $\tau'$, no longer bounded, and for each over arbitrary $\sigma'$, asserting both integrability and the sampling inequality. | ✅ `∀ τ', IsStoppingTime ℱ τ' → Integrable (stoppedValueWithLimit X terminalValue τ') μ ∧ ∀ σ', ∀ hσ', stoppedValueWithLimit X terminalValue (fun ω ↦ min (σ' ω) (τ' ω)) ≤ᵐ[μ] μ[stoppedValueWithLimit X terminalValue τ' \| hσ'.measurableSpace]`. |
| 11 | On $\{\tau' = \infty\}$ the stopped value must be the terminal limit, not an arbitrary time's value. | ✅ `stoppedValueWithLimit X terminalValue τ' ω` is `(τ' ω).recTopCoe (terminalValue ω) fun t ↦ X t ω`, i.e. it returns `terminalValue ω` exactly when $\tau'(\omega) = \infty$. |

## Mistakes to check for

Each row is an error we expect models to make. A formalization that makes any of these is
wrong, even if it compiles.

| # | Mistake | Why it is wrong |
|---|---------|-----------------|
| 1 | Using `stoppedValue X τ'` in the extension clause, with $\tau'$ unbounded. | `stoppedValue X τ' ω` is `X (τ' ω).untopA ω`, and `untopA` returns `Classical.arbitrary ℝ≥0` when the time is $\infty$. So on $\{\tau' = \infty\}$ the statement would compare $X$ at some arbitrary fixed time instead of at $X_\infty$, which is not Kallenberg's claim. |
| 2 | Conditioning on `ℱ i` for a fixed time $i$ rather than on the $\sigma$-algebra of $\sigma$. | $\mathcal{F}_\sigma$ is the whole point of optional sampling; fixing a deterministic time gives a much weaker and different statement. |
| 3 | Stating the sampling relation as an equality. | Equality is the martingale case. For a submartingale only the inequality $X_{\sigma\wedge\tau} \le \mathbb{E}(X_\tau \mid \mathcal{F}_\sigma)$ holds. |
| 4 | Dropping the claim that $X_\tau$ is integrable. | Lean's conditional expectation returns $0$ when its argument is not integrable, so the inequality could hold for a vacuous reason. The integrability claim is what makes the conditional expectation meaningful, and it is asserted in the text. |
| 5 | Formalizing the closure clause as a one-way implication, "uniform integrability implies the extension". | The text says "iff"; the converse is part of the theorem. |
| 6 | Reusing the bounded $\tau$ inside the closure clause instead of quantifying over new optional times. | The clause would then follow from the bounded case and assert nothing new. |
| 7 | Requiring uniform integrability of $X$ itself, or of the stopped family. | The condition is on the positive part $X^+$ indexed by time. Uniform integrability of $X$ is strictly stronger and excludes submartingales the theorem covers. |
| 8 | Working with a filtration indexed by $\mathbb{N}$. | That is the discrete-time optional sampling theorem, where both right-continuity hypotheses become vacuous and the difficulty disappears. |

## Notes on the ground truth

- For the bounded time $\tau$ the first two conclusions use plain `stoppedValue`, whose default value
  at $\infty$ can only occur on a $\mu$-null set thanks to `hτbounded`, so those conclusions are
  sound. Only the closure clause needs the terminal-limit version, and it uses it.
- An earlier version of this file used `stoppedValue` throughout, including inside the closure
  clause, where it compared arbitrary default values instead of $X_\infty$. Mistake row 1 keeps that
  defect on record.
- ⚠️ `hτbounded` is an almost-sure bound where the text says simply "bounded". This makes the theorem
  formally stronger and is harmless; `∀ ω, τ ω ≤ u` is the literal reading.
- Mathlib's `UniformIntegrable` bundles almost-everywhere strong measurability and a uniform $L^1$
  bound alongside the uniform-integrability condition. Both hold automatically for the positive part
  of a submartingale, so nothing beyond the text is being assumed.
- `IsStoppingTime.measurableSpace` is a sub-$\sigma$-algebra of the ambient one in Mathlib, so the
  conditional expectations here are not silently $0$ for that reason.

- Requirement 7 with an equality in place of the sampling inequality.

### Domain-specific pitfalls for this problem

- Optional times take values in $[0,\infty]$; on $\{\tau = \infty\}$ the stopped value has to be the terminal limit $X_\infty$, not an arbitrary default.
- $\mathcal{F}_\sigma$ is the stopped $\sigma$-algebra, not $\mathcal{F}_t$ at some fixed $t$.
- For a submartingale the sampling relation is an inequality in the stated direction.
- Uniform integrability is of the positive parts $X_t^+$, not of $X_t$.
- The right-continuity of both the filtration and the paths is a convention of the chapter and must be stated.
