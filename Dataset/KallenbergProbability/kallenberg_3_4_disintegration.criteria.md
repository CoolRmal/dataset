# Criteria: kallenberg_3_4_disintegration

**Statement:** [kallenberg_3_4_disintegration.md](kallenberg_3_4_disintegration.md) · **Lean:** [kallenberg_3_4_disintegration.lean](kallenberg_3_4_disintegration.lean)

A faithful formalization must carry all three parts of Theorem 3.4 — existence of a factorization $\rho = \nu \otimes \mu$ with $\nu$ equivalent (not equal) to the first marginal and $\mu$ a $\sigma$-finite kernel; $\nu$-a.e. uniqueness of $\mu$ *up to a normalizing density*; the equivalence "some disintegration has a.e. bounded fibres $\iff$ $\hat\rho_S$ is $\sigma$-finite"; and the Markov-kernel refinement when $\nu$ is taken to be $\hat\rho_S$ itself. The junk-value trap is `⊗ₘ`: `Measure.compProd` is built from `Kernel.compProd`, which mathlib *defines to be the zero kernel* when the arguments are not s-finite (`compProd_of_not_isSFiniteKernel_left/right`), so `ν ⊗ₘ κ = ρ` only carries its intended meaning in the presence of `IsSFiniteKernel κ`. The second trap is quantifier placement in (ii): a.e.-boundedness of the fibres is *not* invariant under the normalizations that (ii) itself permits, so it must be existentially, not universally, quantified.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| 4 | Conclusion completeness | All four assertions must be present: (i) existence; (ii) uniqueness up to normalization; (ii') a.e. boundedness $\iff$ $\sigma$-finiteness of $\hat\rho_S$; (iii) the Markov-kernel choice with $\nu = \hat\rho_S$. | ✅ The statement is a four-fold conjunction covering exactly these. ❗ Trap: formalizing only (i) — mathlib's `Measure.compProd`/disintegration API makes that the tempting minimal reading. |
| 5 | Semantic closeness | "Unique up to normalizations" means: if $(\nu,\kappa)$ and $(\nu',\kappa')$ both disintegrate $\rho$, there is a density $c$ with $\nu' = c\,\nu$ and $\kappa = c\,\kappa'$ $\nu$-a.e.
