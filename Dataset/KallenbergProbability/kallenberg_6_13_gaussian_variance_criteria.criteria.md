# Criteria: kallenberg_6_13_gaussian_variance_criteria

**Statement:** [kallenberg_6_13_gaussian_variance_criteria.md](kallenberg_6_13_gaussian_variance_criteria.md) · **Lean:** [kallenberg_6_13_gaussian_variance_criteria.lean](kallenberg_6_13_gaussian_variance_criteria.lean)

This is the Lindeberg–Feller theorem stated as a genuine equivalence, and both sides have to be complete: the left-hand side is the *conjunction* of asymptotic normality of the row sums with the negligibility $\sup_j \operatorname{Var}(\xi_{nj}) \to 0$, and the right-hand side is the Lindeberg condition for *every* $\varepsilon > 0$. The hidden hypothesis is independence: "triangular array" is Kallenberg's term for a rowwise-independent family, and the transcribed sentence never says so, so a candidate working from the prose alone will very plausibly omit it — without rowwise mutual independence the statement is false. The other risk is junk: mathlib's `variance X μ` is `(evariance X μ).toReal`, which silently returns `0` when the second moment is infinite, so the $L^2$ hypothesis is what makes both `variance` and the centering condition mean what they say.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| 1 | Hypothesis completeness | Rowwise **mutual** independence is essential and is only implicit in the word "triangular array". It must be `iIndepFun` per row, not pairwise `IndepFun`, and not independence across rows. | ✅ `hindep : ∀ n, iIndepFun (ξ n) μ`. ❗ Trap: omitting independence entirely (the transcribed statement does not mention it, and the theorem is then false), or using pairwise `IndepFun` (insufficient for the central limit theorem). |
| 2 | Conclusion completeness | The statement is an `↔` between (i) and (ii), and (i) is itself a conjunction. Both directions and both conjuncts of (i) are required. | ✅ `(sumConverges ∧ maximalVarianceVanishes) ↔ lindeberg`. ❗ Trap: formalizing only "Lindeberg ⇒ CLT" (the direction usually quoted), or dropping `sup_j Var(ξ_{nj}) → 0` — without it the equivalence fails. |
| 3 | Junk values | `variance X μ = (evariance X μ).toReal` is `0` for a variable with infinite second moment, and `∫ ω, ξ n j ω ∂μ` is `0` for a non-integrable variable. | 4 | Faithful encoding | (ii) must be $\mathbb{E}(\xi_{nj}^2; \lvert\xi_{nj}\rvert > \varepsilon)$ — the tail contribution above a *strict* threshold — summed over the row, tending to `0` for every `ε > 0`. | ✅ `∀ ε : ℝ, 0 < ε → Tendsto (fun n ↦ ∑ j, ∫ ω, (ξ n j ω) ^ 2 * Set.indicator {x : ℝ \| ε < \|x\|} (fun _ ↦ (1 : ℝ)) (ξ n j ω) ∂μ) atTop (𝓝 0)`, with `ε < \|x\|` strict as in the text. ⚠️ `∫ ω in {ω \| ε < \|ξ n j ω\|}, (ξ n j ω) ^ 2 ∂μ` (a `setIntegral`) is the idiomatic mathlib spelling; the indicator composed with `ξ n j` is correct but roundabout. ❗ Trap: truncating (`min \|ξ\| ε`) instead of restricting to the tail. |
| 5 | Hypothesis completeness | The normalization $\sum_j \operatorname{Var}(\xi_{nj}) \to 1$ and the centering $\mathbb{E}\xi_{nj} = 0$ are *standing hypotheses*, not part of either equivalent condition. | ✅ `hcentered : ∀ n j, ∫ ω, ξ n j ω ∂μ = 0` and `hvariance : Tendsto (fun n ↦ ∑ j, variance (ξ n j) μ) atTop (𝓝 1)` sit above the `↔`. ❗ Trap: folding `hvariance` into condition (i), which changes the theorem. |
| 6 | Faithful encoding | The limit must be the standard normal. Mathlib's `gaussianReal m v` takes `v` to be the **variance**, so `gaussianReal 0 1` is $N(0,1)$; the law of `ζ` is registered with `HasLaw`, which also carries `AEMeasurable ζ μ'`. | ✅ `hζ : HasLaw ζ (gaussianReal 0 1) μ'`. ❗ Trap: passing a standard deviation where a variance is expected, or asserting the conclusion as convergence to `gaussianReal 0 1` as a *measure* while the rest of the statement is phrased through a random variable. |
| 7 | Convergence mode | The row sums must converge **in distribution**, not a.s. or in $L^2$; the sums are over the finite row `Finset.univ : Finset (Fin (k n + 1))`. | ✅ `TendstoInDistribution (fun n ω ↦ ∑ j, ξ n j ω) atTop ζ (fun _ ↦ μ) μ'`. |
| 8 | Mathlib conventions | The array is `ξ : (n : ℕ) → Fin (k n + 1) → Ω → ℝ`, i.e. rows of varying finite length, and `sup_j` is `Finset.univ.sup' (Finset.univ_nonempty_iff.mpr inferInstance)`. | ⚠️ The `+ 1` is there only to make each row nonempty for `sup'`; `Fin (k n)` with `Finset.sup` into `ℝ≥0` or `⨆ j` would allow empty rows and be marginally more faithful.
