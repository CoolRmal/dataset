# Criteria: krylov_sobolev_12_9_12_bessel_kernel

**Statement:** [krylov_sobolev_12_9_12_bessel_kernel.md](krylov_sobolev_12_9_12_bessel_kernel.md) · **Lean:** [krylov_sobolev_12_9_12_bessel_kernel.lean](krylov_sobolev_12_9_12_bessel_kernel.lean)

A faithful formalization must produce **one** kernel $G$, depending on $d$ and $\gamma$ but not on $\phi$, that is radial, nonnegative, of unit $\mathcal{L}_1$ norm, and represents $(1-\Delta)^{-\gamma/2}$ on the whole Schwartz class as a convolution. The characteristic hazard is the Fourier normalization: Krylov's $F(u)(\xi) = (2\pi)^{-d/2}\int e^{-i\xi\cdot x}u\,dx$ makes the symbol of $1-\Delta$ equal to $1+\|\xi\|^2$, whereas mathlib's `𝓕 f ξ = ∫ e^{-2\pi i\langle x,\xi\rangle}f\,dx$ makes it $1+4\pi^2\|\xi\|^2$. Writing $(1+\|\xi\|^2)^{-\gamma/2}$ against mathlib's `𝓕` silently formalizes $(1 - (2\pi)^{-2}\Delta)^{-\gamma/2}$ — an operator whose kernel is *also* radial, nonnegative and of unit mass, so the mistake survives every truth check while formalizing a different operator.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Faithful encoding / Fourier normalization | The symbol must be expressed in the *same* normalization as the Fourier transform being used. With mathlib's `𝓕` (character $e^{-2\pi i\langle x,\xi\rangle}$), $-\Delta$ has symbol $4\pi^2\|\xi\|^2$, so $(1-\Delta)^{-\gamma/2}$ has symbol $(1+4\pi^2\|\xi\|^2)^{-\gamma/2}$. Krylov's constant $c_d = (2\pi)^{-d/2}$ cancels, since it multiplies both sides of the defining relation. | ✅ `IsBesselPotential γ φ v : ∀ ξ, 𝓕 v ξ = ((1 + 4 * π ^ 2 * ‖ξ‖ ^ 2) ^ (-γ / 2) : ℝ) * 𝓕 φ ξ`, with the normalization spelled out in the definition's docstring. ❗ Highest-value trap: `(1 + ‖ξ‖ ^ 2) ^ (-γ / 2)` against mathlib's `𝓕`. |
| 2 | Semantic closeness / quantifier order | $G$ is a single kernel for the operator: `∃ G` must lie **outside** `∀ φ`. A statement of the form "for every $\phi$ there is a $G$ with …" is strictly weaker and is not the theorem. | ✅ `∃ G, (radial) ∧ (nonneg) ∧ (unit 𝓛₁ norm) ∧ ∀ φ v, IsBesselPotential γ φ v → ∀ x, v x = ∫ y, G (x - y) * φ y`. ❗ Predicted error: sinking `∃ G` inside `∀ φ`. |
| 3 | Conclusion completeness | All four assertions are required: the convolution representation (9), radiality ("$G$ is a function depending only on $\|x\|$"), $G \ge 0$, and $\|G\|_{\mathcal{L}_1} = 1$. The last two are what make $G$ a probability density and are used later to estimate $(1-\Delta)^{-\gamma/2}$ in $\mathcal{L}_p$. | ✅ All four, as a conjunction. ❗ Predicted error: keeping only (9), or replacing $\|G\|_{\mathcal{L}_1} = 1$ by $\|G\|_{\mathcal{L}_1} < \infty$. |
| 4 | Faithful encoding / radiality | "Depending only on $\|x\|$" is `∀ x y, ‖x‖ = ‖y‖ → G x = G y`; an equivalent formulation factors $G$ through a function of $\|x\|$. Rotational invariance (`∀ R : O(d), G ∘ R = G`) is equivalent on `EuclideanSpace` and acceptable. | ✅ The level-set form, which needs no extra structure. |
| 5 | Junk values | `eLpNorm G 1 volume = 1` is the literal $\|G\|_{\mathcal{L}_1}$ and is junk-free (it is `∫⁻ ‖G‖ₑ`, defined for every measurable `G`). By contrast `∫ x, G x = 1` would rely on the Bochner integral, which silently returns `0` for a non-integrable `G` — here harmless only because the value is asserted to be `1`. | ✅ `eLpNorm G 1 volume = 1`, which together with `0 ≤ G` also delivers `∫ G = 1` and, in particular, integrability of `G`. |
| 6 | Hypothesis completeness | $\gamma > 0$ is required: for $\gamma \le 0$ the symbol $(1+4\pi^2\|\xi\|^2)^{-\gamma/2}$ does not decay and $(1-\Delta)^{-\gamma/2}$ is not given by convolution with an $\mathcal{L}_1$ function (at $\gamma = 0$ the "kernel" is a Dirac mass). | ✅ `hγ : 0 < γ`. ❗ Predicted error: `0 ≤ γ`. |
| 7 | Semantic closeness / how the operator is presented | $(1-\Delta)^{-\gamma/2}\phi$ is characterized, not constructed: `v` is any function whose Fourier transform is the symbol times $\hat\phi$. Since `𝓕` is injective on the relevant class this pins `v` down, and the theorem then evaluates it. Defining `v` directly as an inverse Fourier transform is equally faithful. | ✅ `∀ φ v, IsBesselPotential γ (fun x ↦ φ x) v → ∀ x, v x = …`. ⚠️ The implication form is vacuous for a `φ` admitting no such `v`; existence does hold for every Schwartz `φ`, so nothing is lost, but a candidate that also asserts existence is stronger and closer to (9) as printed. |
| 8 | Faithful encoding / the convolution | (9) is $\int_{\mathbb{R}^d}G(x-y)\phi(y)\,dy$: the kernel is evaluated at $x - y$ and the integration is in $y$ over all of $\mathbb{R}^d$. Since $G$ is radial, $G(x-y) = G(y-x)$, so the orientation is not detectable here — but a candidate writing $G(x)\phi(y)$ or integrating in $x$ is wrong. | ✅ `∫ y, (G (x - y) : ℂ) * φ y`, with the real kernel coerced into `ℂ` to match the Schwartz function's codomain. |
| 9 | Mathlib conventions | $\mathcal{S}$ is `𝓢(EuclideanSpace ℝ (Fin d), ℂ)`, and the statement must hold for *every* Schwartz function and *every* point $x$, not almost everywhere. | ✅ `∀ (φ : 𝓢(EuclideanSpace ℝ (Fin d), ℂ)) …, ∀ x, …`. ⚠️ Restricting to `C_0^∞` (Krylov's Remark 12.9.11) would be a weaker statement than Theorem 12.9.12, which is stated for `𝒮`. |
