# Criteria: krylov_sobolev_1_5_1_multiplicative_inequality

**Statement:** [krylov_sobolev_1_5_1_multiplicative_inequality.md](krylov_sobolev_1_5_1_multiplicative_inequality.md) · **Lean:** [krylov_sobolev_1_5_1_multiplicative_inequality.lean](krylov_sobolev_1_5_1_multiplicative_inequality.lean)

A faithful formalization must be the *interpolation* inequality $\|u_x\|_p \le N\|u\|_p^{1/2}\|u_{xx}\|_p^{1/2}$ with both exponents equal to $1/2$ and with $N$ quantified **outside** the universally quantified $u$. The two exponents are forced by scaling ($u \mapsto u(c\,\cdot)$), which is also why the theorem fails on bounded domains — Exercise 1.5.3 asks the reader to check exactly that, so the restriction $\Omega \in \{\mathbb{R}^d, \mathbb{R}^d_+\}$ is a hypothesis and not a convenience. Everything else is bookkeeping about which $\mathcal{L}_p$ norm of the vector $u_x$ and the matrix $u_{xx}$ is meant, and about which of Krylov's two equivalent descriptions of $W_p^2(\Omega)$ is used.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Constant dependence / quantifier order | "$N$ is independent of $u$" means $\exists N\,\forall u$. Putting `∃ N` inside `∀ u` makes the statement vacuous: for each fixed $u$ with $\|u\|_p, \|u_{xx}\|_p > 0$ some constant always works. $N$ *may* depend on $d$, $p$ and $\Omega$, all of which are bound earlier. | ✅ `∃ N : ℝ≥0∞, N ≠ ∞ ∧ ∀ u, …` sits after `d`, `p`, `Ω`. ❗ The single most damaging error class for this book; check it in every estimate. |
| 2 | Conclusion completeness / exponents | Both exponents must be $1/2$. Any other pair (e.g. $\|u\|^{1/3}\|u_{xx}\|^{2/3}$) is dimensionally wrong and false; the additive form $\|u_x\|_p \le N(\|u\|_p + \|u_{xx}\|_p)$ is Corollary 1.5.2's precursor and strictly weaker. | ✅ `… ^ (2⁻¹ : ℝ)` on both factors, using `ENNReal.rpow`. ❗ Predicted error: the additive form, or `ε‖u_xx‖ + N‖u‖` (Corollary 1.5.2), which is a different numbered result. |
| 3 | Hypothesis completeness | $\Omega$ must be $\mathbb{R}^d$ or $\mathbb{R}^d_+$. Exercise 1.5.3 states that the assertion is *wrong* on a bounded domain, so a version quantified over arbitrary open $\Omega$ is false. | ✅ `hΩ : Ω = ⊤ ∨ Ω = upperHalfSpace d`, with `Ω : Opens (EuclideanSpace ℝ (Fin d))`. ❗ Predicted error: `IsOpen Ω`, or silently taking $\Omega = \mathbb{R}^d$ only (weaker, but not false). |
| 4 | Faithful encoding | $\|u_x\|_{\mathcal{L}_p(\Omega)}$ is the $\mathcal{L}_p$ norm of the pointwise length $\|u_x(x)\|$ of the gradient vector, and similarly $\|u_{xx}\|$ for the Hessian matrix. Replacing them by $\sum_i\|D_iu\|_p$ or $\max_i\|D_iu\|_p$ changes the statement only by a dimensional constant, which $N$ absorbs. | ✅ `gradNorm D` and `hessNorm D` are the Euclidean/Frobenius lengths, and `eLpNorm _ (ENNReal.ofReal p) (volume.restrict Ω)` is $\|\cdot\|_{\mathcal{L}_p(\Omega)}$. ⚠️ Any of the equivalent norms is acceptable here; a candidate must not, however, silently drop to a single coordinate direction. |
| 5 | Junk values | The derivative family `D` is an explicit hypothesis, not a choice function: the statement asserts the bound for **every** family `D` of generalized derivatives of `u`. Since two such families agree a.e. and `eLpNorm` against `volume.restrict Ω` is a.e.-invariant, this is equivalent to fixing one representative — and it removes `Classical.choose` from the definitions. | ✅ `MemSobolevOn (ENNReal.ofReal p) 2 Ω u` guarantees that all $D^\alpha u$, $\lvert\alpha\rvert \le 2$, exist in $\mathcal{L}_p(\Omega)$, and `IsSobolevFamilyOn 2 Ω u D` names the representatives used on both sides. ❗ Predicted error: dropping the membership hypothesis "because the norms already appear on both sides". |
| 6 | Junk values / `ℝ≥0∞` arithmetic | With `eLpNorm` valued in `ℝ≥0∞`, `⊤ ^ (1/2) = ⊤` and `0 ^ (1/2) = 0`, so the right-hand side degenerates only in the excluded cases. The constant must be finite: `∃ N : ℝ≥0∞` with no finiteness constraint is satisfied by `N = ⊤`. | ✅ `N ≠ (∞ : ℝ≥0∞)` is asserted. ❗ Predicted error: `∃ N : ℝ≥0∞, ∀ u, …` with no `N ≠ ⊤`, which is trivially true. |
| 7 | Semantic closeness / definition of $W_p^k$ | Krylov's official Definition 1.3.1 builds $W_p^k(\Omega)$ from *defining sequences* in $C^k(\bar\Omega)$; Exercise 1.8.8 identifies it, for the domains considered here, with "$u$ and all generalized $D^\alpha u$, $\lvert\alpha\rvert \le k$, lie in $\mathcal{L}_p(\Omega)$". | ⚠️ `MemSobolevOn` uses the generalized-derivative description, which is the standard mathematical reading and equivalent for $\Omega = \mathbb{R}^d, \mathbb{R}^d_+$, but is not literally Definition 1.3.1. A candidate encoding the defining-sequence definition is at least as faithful. |
| 8 | Mathlib conventions | $p \in [1,\infty)$ is a *real* exponent; the `ℝ≥0∞` exponent handed to `eLpNorm` must be `ENNReal.ofReal p`, and `p = ∞` is excluded by the text. | ✅ `p : ℝ` with `hp : 1 ≤ p`, used as `ENNReal.ofReal p`. ❗ Predicted error: `p : ℝ≥0∞` with `1 ≤ p`, which admits `p = ⊤`. |
