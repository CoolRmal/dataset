# Criteria: hardy_average_and_tail_memLp

**Statement:** [hardy_average_and_tail_memLp.md](hardy_average_and_tail_memLp.md) · **Lean:** [hardy_average_and_tail_memLp.lean](hardy_average_and_tail_memLp.lean)

An $L^p(0,\infty)$ membership statement for the Hardy average $\varphi(x) = x^{-1}\int_0^x f$ and the conjugate tail $\psi(x) = \int_x^\infty f(t)/t\,dt$. The quality questions: is “$L^p(0,+\infty)$” encoded as the restricted Lebesgue measure, are $\varphi$ and $\psi$ genuinely well-defined from the hypotheses (they are, by Hölder — so Bochner integrals are faithful here), and is the conclusion exactly membership (the exercise asks no norm bound).

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Faithful encoding | $L^p(0,+\infty)$ = `MemLp · (ENNReal.ofReal p) (volume.restrict (Ioi 0))` — the restricted-measure convention, keeping `f : ℝ → ℝ` total. Hand-rolled `Integrable (fun x ↦ |f x| ^ p)` misses the measurability component of $L^p$; a subtype domain `Ioi (0:ℝ) → ℝ` fights Mathlib's API. | ✅ `MemLp` with `volume.restrict (Ioi 0)`, for hypothesis and both conclusions. |
| 2 | Hypothesis fidelity | The exponent range is exactly $p > 1$ (`hp : 1 < p`, `p : ℝ`), lifted by `ENNReal.ofReal`. The statement is false at $p = 1$, so `1 ≤ p` is wrong; `p < ∞` is automatic from the encoding. | ✅ `hp : 1 < p` with `ENNReal.ofReal p`. ⚠️ Taking `p : ℝ≥0∞` with `1 < p` would also be acceptable but then must separately exclude `p = ∞` (the tail integral defining ψ can diverge for p = ∞); the real-exponent form dodges that corner case. |
| 3 | Junk values | $\varphi(x) = \frac1x\int_0^x f$: for $x > 0$, $f \in L^p(0,\infty) \subseteq L^1(0,x)$ by Hölder on the finite interval, so the interval integral is genuinely defined — Bochner `∫ t in (0)..x, f t` is faithful, and `1/x` is only evaluated at `x ∈ Ioi 0` (the junk value `1/0 = 0` is invisible to `MemLp` on the restricted measure). | ✅ Well-defined; junk confined outside the measure's support. |
| 4 | Junk values | $\psi(x) = \int_x^\infty f(t)/t\,dt$: for $x > 0$, $1/t \in L^{p'}(x,\infty)$ (as $p' > 1$), so by Hölder the integrand is genuinely integrable on `Ioi x` and the Bochner set-integral is faithful — the statement does not lean on junk `∫ = 0`. Division `f t / t` never sees `t = 0` on `Ioi x`, `x > 0`; on `x ≤ 0` the function values are irrelevant to the restricted `MemLp`. | ✅ Well-defined encoding via `∫ t in Ioi x, f t / t`. |
| 5 | Semantic closeness | $\int_0^x$ as `intervalIntegral (0)..x` and $\int_x^{+\infty}$ as a set integral over `Ioi x` are the Mathlib-idiomatic readings of the two integral shapes; endpoints carry no mass, so open/closed choices are immaterial — but a candidate using `Icc 0 x`-style set integrals should be judged equivalent, not preferred. | ✅ `∫ t in (0:ℝ)..x` and `∫ t in Ioi x`. |
| 6 | Conclusion fidelity | The exercise asks exactly membership of *both* functions — a conjunction of two `MemLp` claims. Adding Hardy's norm inequality $\|\varphi\|_p \le \frac{p}{p-1}\|f\|_p$ would be a strictly stronger, different statement; omitting ψ halves the exercise. | ✅ Conjunction of the two memberships, no spurious norm bound. |
| 7 | Mathlib conventions | `MemLp` (Mathlib's current name for $L^p$ membership), `volume.restrict`, `Ioi`, `intervalIntegral` — all standard; the function stays `ℝ → ℝ` with restriction in the measure, matching how Mathlib states one-sided results. | ✅ Conventions followed. |
