## Lebesgue measurability and Lusin's property (N)

**"Lebesgue measurable" is not "Borel".** Throughout this theorem, measurability on $\mathbb{R}^n$ is
with respect to the *completed* Lebesgue σ-algebra: the σ-algebra generated by the Borel sets together
with all subsets of Borel null sets. It is strictly larger than the Borel σ-algebra. A Lebesgue
measurable map is one whose preimages of Borel sets are Lebesgue measurable; this is weaker than Borel
measurability, so a formalization that assumes Borel measurability proves a special case.

**Property (N).** Definition 3.6.8, quoted with the statement: $F$ has property (N) with respect to
$(\mu,\nu)$ when $\nu(F(A)) = 0$ for every $A$ with $\mu(A)=0$. Here $F(A)$ is the forward image; it is
*not* assumed measurable, and $\nu(F(A))$ is to be read as outer measure. Adding a measurability
hypothesis on the image weakens the condition for free.

**Why images are the difficult direction.** Forward images do not behave like preimages: the image of a
Borel set under a Borel map is analytic, and there are analytic sets that are not Borel. So "$F$ takes
measurable sets to measurable sets" cannot be strengthened to "takes Borel sets to Borel sets"; the
right-hand side of the equivalence is genuinely about Lebesgue measurability. The classical example is
the Cantor function, which maps a null set onto a set of positive measure — it fails property (N), and
correspondingly it maps some Lebesgue measurable set to a non-measurable one.

**"Precisely when".** The theorem asserts both directions of the equivalence.
