# Criteria: grafakos_1_3_2_marcinkiewicz_interpolation

**Statement:** [grafakos_1_3_2_marcinkiewicz_interpolation.md](grafakos_1_3_2_marcinkiewicz_interpolation.md) · **Lean:** [grafakos_1_3_2_marcinkiewicz_interpolation.lean](grafakos_1_3_2_marcinkiewicz_interpolation.lean)

A faithful formalization must interpolate between two *weak*-type endpoint estimates for a merely *sublinear* $T$ and produce a *strong* $(p,p)$ bound with Grafakos's explicit constant $A = 2[\tfrac{p}{p-p_0}+\tfrac{p}{p_1-p}]^{1/p}A_0^{\frac{p_0}{p}\frac{p_1-p}{p_1-p_0}}A_1^{\frac{p_1}{p}\frac{p-p_0}{p_1-p_0}}$. The two hard encoding questions are (i) $L^{p,\infty}$: this Mathlib has **no** `wnorm`/`MemWLp`/`HasWeakType` (grep confirms the identifiers are absent), so the weak-type quasinorm must be hand-rolled, and the `sup` over $\alpha$ in $\|F\|_{L^{p,\infty}}=\sup_\alpha \alpha\,d_F(\alpha)^{1/p}$ has to be traded for a universally quantified $\alpha$ with the $p$-th power cleared correctly; and (ii) the domain of $T$: Grafakos's $T$ lives on $L^{p_0}+L^{p_1}$ and lands in *measurable* functions, and dropping that last clause is exactly what makes the `MemLp (T f)` half of the conclusion unreachable.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| 4 | Faithful encoding (sublinearity) | Marcinkiewicz's whole point is that $T$ need only be sublinear: $\|T(f+g)\| \le \|Tf\|+\|Tg\|$ pointwise and $\|T(cf)\| = \lvert c\rvert\,\|Tf\|$ (Grafakos, Definition 1.3.1). | ✅ `IsSublinearOperator T` is `T 0 = 0 ∧ (∀ f g x, ‖T (f + g) x‖ ≤ ‖T f x‖ + ‖T g x‖) ∧ ∀ c f x, ‖T (c • f) x‖ = ‖c‖ * ‖T f x‖`, matching the text (the `T 0 = 0` conjunct is redundant, being the `c = 0` instance). ❗ Trap: formalizing `T : (X → ℂ) →ₗ[ℂ] (Y → ℂ)` — that is the Riesz–Thorin hypothesis and yields a strictly weaker theorem. |
| 5 | Hypothesis completeness (**unsound as stated**) | The text requires $T$ to take "values in the space of measurable functions on $Y$". `HasStrongType … = ∀ f, MemLp f p μ → MemLp (T f) p ν ∧ eLpNorm (T f) p ν ≤ A * eLpNorm f p μ`, and `MemLp` bundles `AEStronglyMeasurable (T f) ν`. Sublinearity plus the two weak-type bounds do **not** entail a.e.-strong-measurability of `T f` (unlike the linear case, one cannot write $Tf = Tf_0 + Tf_1$). | ❗ The measurability hypothesis is missing, so the conclusion's `MemLp (T f) (ENNReal.ofReal p) ν` conjunct is not derivable: take $Tf := \varphi \cdot S f$ with $\varphi$ non-measurable of modulus $1$ and $S$ measurable — all hypotheses survive, the conclusion fails. A candidate should add `hTmeas : ∀ f, AEStronglyMeasurable (T f) ν` (or state only the `eLpNorm` inequality, which is junk-free since `∫⁻` is defined for arbitrary functions). |
