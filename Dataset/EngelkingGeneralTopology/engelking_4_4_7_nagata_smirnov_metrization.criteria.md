# Criteria: engelking_4_4_7_nagata_smirnov_metrization

**Statement:** [engelking_4_4_7_nagata_smirnov_metrization.md](engelking_4_4_7_nagata_smirnov_metrization.md) · **Lean:** [engelking_4_4_7_nagata_smirnov_metrization.lean](engelking_4_4_7_nagata_smirnov_metrization.lean)

A faithful formalization must state a biconditional between metrizability *of the given topology* and the conjunction "regular (in Engelking's sense, i.e. regular $+\ T_1$) **and** possessing a base that is a countable union of locally finite families". Two failure modes dominate: the separation convention — mathlib's `RegularSpace` omits $T_1$, and without it the theorem is plainly false — and the metrizability side, where a conclusion of the form "there exists a metric" must be tied to the ambient topology rather than merely asserting that some metric space structure exists. The $\sigma$-locally finite base must also be encoded so that the *base* is the union of the countably many families, each of which (not the base itself) is locally finite.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Separation axioms (the Engelking convention) | Engelking's "regular" includes $T_1$; mathlib's `RegularSpace` does not. Omitting $T_1$ makes the biconditional **false**: the two-point indiscrete space satisfies mathlib's `RegularSpace` and has the single-element base $\{X\}$ (a one-element, hence locally finite, family), yet is not metrizable. | ✅ `[T1Space X]` is an instance hypothesis, so `RegularSpace X` on the right-hand side is exactly Engelking's regularity. ❗ Predicted error: `MetrizableSpace X ↔ RegularSpace X ∧ …` with no $T_1$ anywhere. A candidate using `T3Space X` (= `T0Space` + `RegularSpace`) in the right-hand side instead is equally faithful and should be accepted. |
| 2 | Faithful encoding (metrizability) | The left-hand side must say that the *given* topology is induced by a metric. `TopologicalSpace.MetrizableSpace X` unfolds to a uniformity `u` with `u.toTopologicalSpace = t` and countably generated `𝓤 X`, plus `T0Space` — so the topology equality is built in. A candidate producing `∃ d : MetricSpace X, True`, or an unrelated `[MetricSpace X]` instance without a `toTopologicalSpace = ‹_›` claim, states something strictly weaker (every type admits *some* metric structure if it is nonempty and small enough). | ✅ `MetrizableSpace X` on the left of the `↔`. A candidate writing `∃ m : MetricSpace X, m.toTopologicalSpace = ‹TopologicalSpace X›` is equally faithful. ❗ Predicted error: unanchored metric existence. |
| 3 | Faithful encoding ($\sigma$-locally finite base) | `HasSigmaLocallyFiniteBase` must say: there are families $\mathcal{B}_n$ ($n \in \mathbb{N}$), each **locally finite**, whose union $\bigcup_n \mathcal{B}_n$ is a **base** for the topology. Requiring the base as a whole to be locally finite is a wildly stronger (essentially never satisfied) condition; requiring only that each $\mathcal{B}_n$ be a base is nonsense. | ✅ `∃ (ι : ℕ → Type v) (B : ∀ n, ι n → Set X), IsTopologicalBasis {V | ∃ n i, B n i = V} ∧ ∀ n, LocallyFinite (B n)`. Openness of the members is not stated separately but follows from `IsTopologicalBasis.eq_generateFrom` together with `sUnion_eq`, so nothing is missing. |
| 4 | Conclusion completeness | Both right-hand conjuncts are needed and neither may migrate into the hypotheses: a candidate assuming `[RegularSpace X]` as an instance and stating `MetrizableSpace X ↔ HasSigmaLocallyFiniteBase X` proves a weaker theorem (the `←` direction no longer has to derive regularity — trivial — but the `→` direction loses the content that metrizable spaces are regular). | ✅ `MetrizableSpace X ↔ RegularSpace X ∧ HasSigmaLocallyFiniteBase X`, both directions, both conjuncts. |
| 5 | Semantic closeness (which metrization theorem) | The $\sigma$-locally finite condition must not be replaced by second countability: `[SecondCountableTopology X]` + regular + $T_0$ $\Rightarrow$ metrizable is the **Urysohn** metrization theorem, which mathlib already has (`TopologicalSpace.metrizableSpace_of_t3_secondCountable`) and which is a strictly weaker statement (it fails to characterize metrizability — an uncountable discrete space is metrizable but not second countable). | ✅ The base is $\sigma$-locally finite, not countable. ❗ Predicted error: a candidate "simplifying" to a countable base, producing a theorem already in mathlib. |
| 6 | Mathlib conventions | Mathlib has no $\sigma$-locally finite base predicate and no Nagata–Smirnov theorem (checked), so the custom definition is required; the surrounding pieces are the right mathlib ones: `TopologicalSpace.IsTopologicalBasis` for "base", `LocallyFinite` (the indexed-family version) for local finiteness, `MetrizableSpace` for metrizability. | ✅ Correct reuse throughout; no hand-rolled substitute for a notion mathlib already provides. |
| 7 | Universe hygiene | `HasSigmaLocallyFiniteBase` indexes each layer by `ι n : Type v` with `v` a free universe parameter, so the biconditional is implicitly asserted for every universe `v`; for `v` strictly below the universe of `X` the right-to-left direction may not even be satisfiable by cardinality. | ⚠️ Acceptable in practice (the dataset instantiates at `Type`), but indexing the layers by subtypes of `Set X` (i.e. `Type u`), or stating the base as a `Set (Set X)` together with a decomposition `Set X → ℕ`, removes the ambiguity. |
