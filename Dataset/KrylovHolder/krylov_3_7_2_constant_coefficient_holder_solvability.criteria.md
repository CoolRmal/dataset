# Criteria: krylov_3_7_2_constant_coefficient_holder_solvability

**Statement:** [krylov_3_7_2_constant_coefficient_holder_solvability.md](krylov_3_7_2_constant_coefficient_holder_solvability.md) · **Lean:** [krylov_3_7_2_constant_coefficient_holder_solvability.lean](krylov_3_7_2_constant_coefficient_holder_solvability.lean)

Everything here rides on the scaffolding: "$f \in C^{k+\delta}(\mathbb{R}^d)$", "$u \in C^{k+m+\delta}(\mathbb{R}^d)$", "$L$ uniformly elliptic of order $m$ with constant coefficients" and "$L_\lambda u = Lu - \lambda u$" are all custom definitions, and the theorem is a bare existence-and-uniqueness claim on top of them. So the audit is really an audit of `HolderOn`/`holderGauge` (do they contain exactly the derivatives Krylov's $|u|_{k+\delta}$ contains? do they bundle smoothness, or would a junk-valued gauge let a non-differentiable function into $C^{k+\delta}$?) and of `EllipticOperatorData.principalSymbol` (is it Krylov's ellipticity, and for which $\lambda$ is the resulting operator $L_\lambda$ actually invertible?). The last question is where this statement breaks: the admissible set of $\lambda$ is a genuine mathematical hypothesis, not a formality.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Hypothesis completeness / solution concept | The set of admissible $\lambda$ must be compatible with the sign convention chosen for ellipticity. With `principalSymbol` reading $\kappa\|\xi\|^m \le \sum_{\lvert\alpha\rvert=m} a^\alpha \xi^\alpha$, the Laplacian is admissible ($\kappa = 1$), and $L_\lambda = \Delta - \lambda$ is boundedly invertible on $C^{k+\delta}$ only for $\lambda > 0$: for $\lambda < 0$ it is the Helmholtz operator. | ❗ **Genuine defect: the ground truth is false as stated.** `hlam : lam ≠ 0` with `lam : ℝ` admits $\lambda < 0$. Take $d = 1$, $m = 2$, `L u = u''` (data: `terms = {(2)}`, `coefficient = 1`, `ellipticityConstant = 1`), $\lambda = -1$, $f = 0$. Then $u \equiv 0$ and $u = \sin$ both satisfy `HolderOn (k+2+δ) univ u ∧ ShiftedEllipticEquation L (-1) u 0` (all derivatives of $\sin$ are bounded and Lipschitz, so every `holderGauge` is finite), contradicting `∃!`. The faithful hypothesis is a one-sided condition on $\lambda$ (or complex $\lambda$ in a resolvent sector), matching whichever sign convention `principalSymbol` fixes. |
| 2 | Faithful encoding of $C^{k+\delta}$ | Krylov's norm is $\sum_{j\le k}[u]_j + [u]_{k+\delta}$: *all* derivatives of order $\le k$ in sup norm, plus the $\delta$-quotient of the derivatives of order exactly $k$, both supremized over the whole set. | ✅ `holderGauge k δ Ω u` takes `⨆ α : {α // ∑ i, α i ≤ k}, ⨆ x : Ω, ENNReal.ofReal \|multiDerivative α u x\|` joined (`⊔`) with `⨆ α : {α // ∑ i, α i = k}, ⨆ x y : Ω, ⨆ (_ : x ≠ y), ENNReal.ofReal (\|D^α u x - D^α u y\| / ‖x - y‖ ^ δ)` — the same derivatives, the same index sets, the same sup over $\Omega \times \Omega$. ⚠️ It is a maximum where Krylov takes a sum; the two are equivalent up to a factor depending only on $d,k$, which is invisible here (no constants are asserted) but would matter in a statement about sharp constants. |
| 3 | Space membership vs finite norm / derivative junk | "$u \in C^{k+m+\delta}$" must be genuine membership. A finite `holderGauge` alone is *not* enough: `multiDerivative` is built from `fderiv`, which is `0` off the differentiability locus, so a bounded nowhere-differentiable function has finite gauge and would be admitted. | ✅ `HolderOn r Ω u` requires `ContDiffOn ℝ k u Ω` alongside `holderGauge k δ Ω u < ∞`, with the same $k$ as the gauge's top order. Since $\Omega = $ `univ` here, `ContDiffOn` gives genuine `fderiv`s and `multiDerivative α u` really is $D^\alpha u$. ❗ Predicted error: encoding $u \in C^{k+m+\delta}$ as a finiteness condition only. |
| 4 | Junk values | The gauge is a supremum over an in general unbounded family; a real-valued `sSup` would return `0` and silently certify membership. Also the difference quotient divides by $\|x-y\|^\delta$. | ✅ `holderGauge` is `ℝ≥0∞`-valued, so unboundedness gives `∞` and `< ∞` is a real condition; the quotient is guarded by `⨆ (_ : (x : Fin d → ℝ) ≠ y)`, so no division by zero. ⚠️ The top-order quotient could reuse mathlib's `HolderOnWith`/`eHolderNorm` (as the companion `HolderOnReal` does) instead of a hand-rolled quotient. |
| 5 | Uniform ellipticity | Krylov's condition is $\sum_{\lvert\alpha\rvert=m} a^\alpha \xi^\alpha \ge \kappa\|\xi\|^m$ for all $\xi$, with $\kappa > 0$. | ✅ `principalSymbol : ∀ x ξ, ellipticityConstant * ‖ξ‖ ^ m ≤ ∑ α ∈ terms with ∑ i, α i = m, coefficient α x * ∏ i, (ξ i) ^ (α i)` is exactly that, with `∏ i, (ξ i) ^ (α i) = ξ^α`, plus `ellipticityConstant_pos`. ⚠️ `‖ξ‖` on `Fin d → ℝ` is the sup norm, so $\kappa$ differs from the Euclidean one by a factor $d^{m/2}$; the *class* of uniformly elliptic operators is unchanged. Note that for odd $m$ the condition is unsatisfiable over $\mathbb{R}$ (replace $\xi$ by $-\xi$), so those cases are vacuous — harmless. |
| 6 | Conclusion completeness | Existence **and** uniqueness. The uniqueness half is the easy one to drop, and it is where the $\lambda$-hypothesis earns its keep. | ✅ `∃! u, HolderOn (k + m + δ) univ u ∧ ShiftedEllipticEquation L lam u f`, and since the domain is all of $\mathbb{R}^d$ the `∃!` (equality of functions) is the right notion — contrast the domain problems in this book, where uniqueness must be stated as `Set.EqOn` on the closure. ❗ Predicted error: `∃ u` only, or a uniqueness clause quantified over $v$ without the regularity hypothesis `HolderOn (k+m+δ) univ v` (uniqueness is false in a larger class). |
| 7 | Solution concept | $L_\lambda u = f$ pointwise everywhere, classically — not a.e., not distributionally. | ✅ `ShiftedEllipticEquation L lam u f : ∀ x, L u x - lam * u x = f x`, with `L u x` given by `EllipticOperatorData.formula` as $\sum_{\alpha} a^\alpha D^\alpha u(x)$; the sign convention $L_\lambda = L - \lambda$ matches the text. |
| 8 | Hypothesis completeness | $m \ge 1$, $k \ge 0$ an integer, $0 < \delta < 1$, and the coefficients genuinely constant. | ✅ `hm : 0 < m`, `k : ℕ` unconstrained, `hδ : 0 < δ ∧ δ < 1`, and `ConstantCoefficientEllipticOperator m L` adds `∀ α ∈ data.terms, ∀ x y, data.coefficient α x = data.coefficient α y` — constancy is imposed exactly on the multi-indices that `formula` uses. ⚠️ `HolderOn` itself only requires `0 ≤ δ' < 1` in its internal decomposition `r = k' + δ'`, but that decomposition is uniquely determined by $r$, so `HolderOn (k+δ)` unambiguously means $C^{k+\delta}$ here. |
