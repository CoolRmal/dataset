# Criteria: mattila_8_8_frostman_lemma

**Statement:** [mattila_8_8_frostman_lemma.md](mattila_8_8_frostman_lemma.md) · **Lean:** [mattila_8_8_frostman_lemma.lean](mattila_8_8_frostman_lemma.lean)

A faithful formalization must state the equivalence "$\mathcal H^s(B) > 0$ iff $B$ carries a measure $\mu \in \mathcal M(B)$ with the growth bound $\mu(B(x,r)) < r^s$", *and* the quantitative refinement that such a $\mu$ can be found with $\mu(B) > c\,\mathcal H^s_\infty(B)$ — the refinement being a strengthening of the **forward** direction, available only when $\mathcal H^s(B) > 0$. Two things carry all the risk: the placement of that "moreover" clause relative to the biconditional, and the definition of the Hausdorff content $\mathcal H^s_\infty$, whose infimum is over covers with *no diameter restriction* and therefore must handle unbounded covering sets correctly.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Conclusion completeness / scope of "moreover" | The refinement "we can find $\mu$ so that $\mu(B) > c\,\mathcal H^s_\infty(B)$" is a strengthening of the ⟹ direction; it is only available when $\mathcal H^s(B) > 0$. It must therefore live **inside** the forward implication (or be conditioned on `0 < μH[s] B`), never as a free-standing conjunct. | ❗ The ground truth reads `(0 < μH[s] B ↔ ∃ μ, …) ∧ (∃ μ, … ∧ c * hausdorffContent s B ≤ μ B)`: the second conjunct is asserted for **every** Borel `B` and every `s > 0`. At `B = ∅` it demands `μ ≠ 0` with `μ ∅ᶜ = μ univ = 0`, which is impossible — `False` is derivable from the theorem's type in four lines. This is a genuine defect, not a stylistic one. |
| 2 | Junk values | $\mathcal H^s_\infty(A) = \inf \sum_i d(E_i)^s$ over arbitrary countable covers. In mathlib `Metric.diam` is `(EMetric.diam ·).toReal` and is therefore **`0` on unbounded sets** (`Metric.diam_eq_zero_of_unbounded`), so a cover by unbounded sets contributes `0`. The content must be built from `EMetric.diam` in `ℝ≥0∞`. | ❗ `hausdorffContent s A = ⨅ U, ⨅ (_ : A ⊆ ⋃ i, U i), ∑' i, ENNReal.ofReal (diam (U i)) ^ s` uses `Metric.diam`; taking `U i = univ` gives `0`, so `hausdorffContent s A = 0` for **every** set in an unbounded space and every `s > 0` (checked in Lean). The `c * hausdorffContent s B ≤ μ B` clause is consequently vacuous. `∑' i, EMetric.diam (U i) ^ s` is the fix. |
| 3 | Semantic closeness | Mattila's $\mu \in \mathcal M(B)$ means: a Radon measure with $0 < \mu(\mathbb{R}^n) < \infty$ and **compact** support $\mathrm{spt}\,\mu \subset B$. The growth bound $\mu(\bar B(x,r)) < r^s$ does not by itself force finite total mass, so compactness of the support (or finiteness) is real content. | ⚠️ Ground truth has `IsFiniteMeasureOnCompacts μ ∧ μ.InnerRegular ∧ μ ≠ 0 ∧ μ Bᶜ = 0` — Radon, nonzero, concentrated on `B`. Compact support and total finiteness are dropped. This weakens ⟹ and strengthens ⟸ (which still holds by the mass distribution principle), so the biconditional survives, but the `M(B)` content is lost. An `IsCompact μ.support ∧ (μ.support ⊆ B)` clause would be faithful. |
| 4 | Semantic closeness | "$\mu$ lives on $B$" is rendered as `μ Bᶜ = 0` (concentrated on `B`) rather than `μ.support ⊆ B`. For Borel `B` these genuinely differ, since the support is closed. | ⚠️ `μ Bᶜ = 0` is the standard measure-theoretic reading and is what the proof produces, but it is not literally the book's $\mathrm{spt}\,\mu \subset B$. |
| 5 | Semantic closeness / quantifier order | $c > 0$ "depends only on $n$": the constant must be quantified outside `s` and `B` but may depend on the implicit `n`. It must also be **positive**, or the refinement is vacuous. | ✅ `∃ c : ℝ≥0∞, 0 < c ∧ c < ∞ ∧ ∀ (s : ℝ) (B), …`. ❗ Predicted error: `∀ B, ∃ c, …`, or omitting `0 < c`. |
| 6 | Faithful encoding | The growth bound is the **strict** inequality `μ (closedBall x r) < ENNReal.ofReal (r ^ s)`, for *all* $x \in \mathbb{R}^n$ (not just $x \in B$) and *all* $r > 0$ (no small-radius restriction). `closedBall` matches Mattila's $B(x,r)$; `r ^ s` is `Real.rpow`, positive for `r > 0`. | ✅ All four points. ❗ Predicted error: relaxing to `≤`, restricting to `x ∈ B`, or inserting a constant `C * r^s` (which is the more common textbook form but not what 8.8 states). |
| 7 | Conclusion completeness | Both directions of the biconditional must be present, in the direction stated ($\mathcal H^s(B) > 0$ on the left). Note this is a *measure* statement, not a content statement: `0 < μH[s] B`, with `μH[s]` mathlib's unnormalized Hausdorff measure, matching Mattila's convention. | ✅ `0 < μH[s] B ↔ ∃ μ, …`. |
| 8 | Mathlib conventions | Radon-ness of an existentially quantified measure cannot use instance binders, so `IsFiniteMeasureOnCompacts μ` and `Measure.InnerRegular μ` correctly appear as propositions (both are classes, usable as plain `Prop`s). On $\mathbb{R}^n$ inner regularity is automatic for locally finite Borel measures, so the second conjunct is redundant but harmless. | ✅ Appropriate here (contrast the same notions as *hypotheses* in `mattila_14_10`, where instance binders would be idiomatic). |
