# Criteria: mattila_8_19_compact_subsets_of_finite_hausdorff_measure

**Statement:** [mattila_8_19_compact_subsets_of_finite_hausdorff_measure.md](mattila_8_19_compact_subsets_of_finite_hausdorff_measure.md) · **Lean:** [mattila_8_19_compact_subsets_of_finite_hausdorff_measure.lean](mattila_8_19_compact_subsets_of_finite_hausdorff_measure.lean)

A faithful formalization must state an *equality* in $\overline{\mathbb{R}}_{\ge 0}$ between $\mathcal{H}^s(X)$ and the supremum of $\mathcal{H}^s(C)$ over the compact subsets $C$ of *finite* $\mathcal{H}^s$ measure — the whole point being that the equality survives when $\mathcal{H}^s(X) = \infty$, in which case the supremum is over sets none of which realizes it. The junk-value risk is therefore concentrated in the encoding of a supremum over a *conditioned subfamily* (a `⨆ … ⨆ (_ : P)` telescope silently contributes `⊥ = 0` for indices failing `P`) and in accidentally forcing the left-hand side to be finite.

Legend: ✅ ground truth satisfies the criterion · ⚠️ ground truth acceptable but improvable · ❗ trap — known/likely model error to check in candidate statements.

| # | Category | Criterion / potential error | Assessment of ground truth |
|---|----------|-----------------------------|----------------------------|
| 1 | Semantic closeness | The right-hand side is $\sup\{\mathcal H^s(C) : C \text{ compact},\ \mathcal H^s(C) < \infty\}$, i.e. a supremum over a subfamily, not an existence statement. | ✅ `⨆ C : Set X, ⨆ (_ : IsCompact C), ⨆ (_ : μH[s] C < ∞), μH[s] C`. The `⨆ (_ : P)` telescope contributes `0` for `C` failing a condition, which is harmless here: every term is `≥ 0` and `C = ∅` already qualifies, so the sup is over a nonempty family. ❗ Predicted error: replacing the sup by `∃ C, IsCompact C ∧ μH[s] C < ∞ ∧ μH[s] C = μH[s] univ`, which is false whenever $\mathcal H^s(X) = \infty$. |
| 2 | Conclusion completeness | Both inequalities are asserted by the equality. `≥` is trivial monotonicity; the content is `≤`, i.e. inner approximation by *finite-measure* compacta. A candidate that adds `μH[s] (univ : Set X) < ∞` as a hypothesis (or states only `≤`/only `≥`) removes the theorem's substance. | ✅ Stated as a single equation `μH[s] (Set.univ : Set X) = ⨆ …` with no finiteness assumption on the ambient measure. |
| 3 | Junk values / ℝ≥0∞ | Both sides must live in `ℝ≥0∞` so that `∞ = ∞` is expressible; the side condition must be `μH[s] C < ∞` (`< ⊤`), never a real-valued bound or a coercion through `ENNReal.toReal` (which sends `∞ ↦ 0`). | ✅ Everything is `ℝ≥0∞`-valued; the constraint is literally `μH[s] C < ∞`. |
| 4 | Faithful encoding | $\mathcal H^s(X)$ — the measure of the whole space — must be `μH[s] (Set.univ : Set X)`, not `μH[s]` applied to some distinguished subset, and $C \subset X$ must range over `Set X` with `IsCompact C` (in a compact metric space this is the same as closed). | ✅ `Set.univ` on the left, `C : Set X` with `IsCompact C` on the right. |
| 5 | Hypothesis completeness | Compactness of the ambient space is a genuine hypothesis of 8.19 and must appear; so must the metric structure (the result is about $\mathcal H^s$ on a metric space, not about an arbitrary measure). | ✅ `[MetricSpace X] [CompactSpace X]`. ❗ Predicted error: dropping `[CompactSpace X]`, or specialising to `EuclideanSpace ℝ (Fin n)` — the latter is not unfaithful but loses the stated generality, which the ground truth preserves via a universe-polymorphic `X`. |
| 6 | Mathlib conventions | `μH[s]` is `MeasureTheory.Measure.hausdorffMeasure s = mkMetric (fun r ↦ r ^ s)` — the *unnormalized* Hausdorff measure $\inf \sum d(E_i)^s$, exactly Mattila's convention. Here the statement is homogeneous (both sides scale together), so any normalization would do, but reusing mathlib's `μH[·]` rather than hand-rolling a content is the right call. `[MeasurableSpace X] [BorelSpace X]` are the instances `μH[·]` requires and add no mathematical content. | ✅ All conventions followed. |
| 7 | Hypothesis completeness | `hs : 0 < s` is *not* in the textbook statement. It is a harmless restriction (Mattila only ever considers $s \ge 0$; for $s = 0$, $\mathcal H^0$ is counting measure and the identity still holds), but it does narrow the theorem. | ⚠️ Acceptable; `0 ≤ s`, or no restriction at all, would be closer to the text. Note that `hs` is not used anywhere else in the statement. |
